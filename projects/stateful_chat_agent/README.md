# Stateful Chat Agent

Este proyecto implementa un agente conversacional con memoria (stateful). El agente es capaz de mantener el contexto de la conversación a lo largo del tiempo, permitiéndole ofrecer respuestas más coherentes, personalizadas y contextualmente informadas.

## 🚀 Características

- Retención de contexto entre turnos de conversación.
- Capacidad de adaptar respuestas según interacciones previas.
- Ideal para flujos conversacionales complejos o prolongados.

## 🧠 ¿Qué es un agente stateful?

Un agente stateful conserva un "estado" o memoria de lo que ha ocurrido anteriormente en la conversación. Esto le permite ofrecer una experiencia más natural e inteligente, recordando preguntas previas, nombres, temas tratados, etc.

## 📦 Tecnologías utilizadas

- LangChain
- LangGraph
- OpenAI (ChatOpenAI)
- Python
